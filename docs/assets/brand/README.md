# Voice Agent identity

The current v4 mark combines a rounded speech bubble with three audio slots. Its compact silhouette represents spoken conversation without a letterform or circular arrows.

## Current assets

- `logo-v4-source.png`: full-resolution ImageGen master with alpha transparency.
- `logo-v4.png`: 512 px production mark for light and dark surfaces.
- `wordmark-v4.png` / `wordmark-dark-v4.png`: native system typography paired with the generated mark.
- `../favicon-v4.png`: 64 px transparent favicon.
- Companion copies: `src/voice_agent/web/static/logo-v4.png` and `src/voice_agent/web/static/favicon-v4.png`, relative to the repository root.

Preserve the square aspect ratio and built-in clear space. Earlier v1/v2/v3 assets are previous explorations; current app, docs, and README references use v4. Assets are covered by the repository license.

Generated with the built-in ImageGen tool. Resized production exports preserve the generated alpha; wordmarks use browser-rendered text.

## Final prompt

Use case: logo-brand
Asset type: final production logo symbol for Voice Agent, a premium futuristic conversational voice app. Must work at 24–32px in the app header and as a favicon.
Primary request: Design one clean, distinctive speech-and-audio mark. A single substantial rounded-square speech bubble, slightly wider than tall, with one small softly rounded speech tail at the lower-left. In its center, cut three vertical rounded audio slots out of the solid bubble: a short slot, a tall slot, and a medium slot, all centered on a common horizontal baseline. The three slots are transparent negative space, not colored objects. Keep the symbol bold, beautifully balanced and instantly readable as voice conversation.
Style/medium: immaculate minimal flat graphic logo, confident simple silhouette, generous spacing, softly rounded precise geometry.
Color palette: one flat opaque periwinkle-blue #879df5 throughout the bubble. No gradient.
Composition/framing: one centered standalone symbol on a square genuinely transparent canvas. Occupy about 78% of the square, preserve clear space on every side.
Constraints: no V shape, no letter, no circular segments, no loop, no arrows, no recycling symbol, no loading spinner, no dustbin, no three-fold symmetry, no microphone illustration, no text, no border, no tiny details, no shading, no texture, no glow, no 3D, no mockup, no watermark.
