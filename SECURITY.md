# Security Policy

## Supported Versions

Security updates are provided for the latest version on the `main` branch.

## Reporting a Vulnerability

Please do not report vulnerabilities in public GitHub issues.

Report privately by email to:

- opensource@natelin.dev

Please include:

- A description of the issue and potential impact
- Reproduction steps or proof of concept
- Any suggested remediation

You can expect an initial response within 5 business days.
